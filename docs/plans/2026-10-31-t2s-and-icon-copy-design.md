# 频道名繁体统一转简体 + 图标库复制外链 设计

日期：2026-10-31。两个独立小需求，一次实施。

## 需求一：频道名繁体统一转简体

### 背景

- 库内 1965 个对外频道中 841 个（43%）含繁体字，繁简并存导致同一频道重复入库
  （如「ABC Australia 澳洲公广频道 / 澳洲公廣頻道」两条记录）
- `/api/epg?ch=` 用繁体查询无法命中简体频道名
- 节目标题**不转换**（用户决策：只转频道名）

### 转换层选型

新建 `internal/t2s` 包：自嵌字符级繁→简映射表（约 2600 单字对，数据取自
OpenCC 字级表），单函数 `Convert(string) string`，O(n) 单遍扫描。

不引入 opencc 库：频道名为封闭词汇场景，字级映射 100% 覆盖，词级歧义
（頭髮/头发）不存在；纯 Go opencc 嵌入词典约 1.5MB，为此多 1.5MB 二进制
与一个外部依赖违反 YAGNI。

### 改动点

| 位置 | 改动 |
|---|---|
| syncer 解析频道名后 | `name = t2s.Convert(name)` 入库。存量随下轮同步全删重写自然消失，繁简重复合并自然发生，无需数据迁移脚本 |
| handleEPG 的 `ch` 参数 | 同样转换后再查，繁体输入命中简体频道 |
| /icon/{name} | 无需改动：频道名已统一简体，与图标库简体文件名匹配率自然提升 |

### 存量配置迁移（启动时一次性、幂等）

- `epg_hidden_channels`（1761 条用户勾选隐藏）中繁体名在频道转简体后失效，
  被隐藏频道会全部重新出现 —— 启动时 SELECT 全部 → 转换 → 差异 UPDATE，
  转换后与现有记录撞名则跳过
- `epg_bindings`（4 条手动绑定）同样处理
- DIYP 返回格式不变（约束：/api/epg 保持 DIYP 默认格式），仅名字统一简体

### 测试（TDD）

- t2s 单测：繁体样本、纯简体不变、繁简混合、空串、纯英文数字原样
- syncer 测试：繁体频道名入库为简体
- handleEPG 测试：繁体 ch 命中简体频道，DIYP 字段完整
- hidden 迁移测试：转换生效、撞名跳过、二次启动幂等

### 上线验证

1. 重启（启动迁移执行）→ 触发全部源同步
2. 断言：库内繁体频道名清零、繁简重复对消失
3. `curl /api/epg?ch=衛視中文台` → 200 命中
4. 后台抽查原繁体隐藏频道仍隐藏

### 风险与回退

- 个别生僻字漏转仅影响该频道查询，补表即可，无数据损坏
- 无表结构变更；回退 = 还原代码重启，下轮同步还原繁体名

## 需求二：图标库卡片复制外链按钮

每个图标卡片（替换/绑定/删除按钮组旁）加「复制」按钮，点击复制对外直链：

```
${location.origin}/icon/${encodeURIComponent(文件名去后缀)}
```

- 用 `/icon/{name}` 对外接口（自动匹配 + 手动绑定优先），不用
  `/api/admin/icons/raw`（管理接口带 token，外发泄漏凭据）
- 文件名去扩展名：/icon/{name} 按去后缀名匹配（如「北京卫视.png」→ /icon/北京卫视）
- `navigator.clipboard.writeText` + toast「已复制」；clipboard 不可用时
  降级选中文本提示手动复制
